Cloud saving (GitHub)

Every set is saved to a JSON file in a GitHub repo, so your log lives in the cloud and follows you across devices. A copy is also cached in this browser so the app still opens offline. Use a private repo and a fine-grained token limited to that repo with Contents: Read and write. The token stays in this browser only.

If you ever clear your browser data, open this link (or re-enter the token) on that device and your whole log comes back from GitHub. The link contains your token, so keep it somewhere private like a password manager.
